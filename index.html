AI Claude Code

A personal assistant used by one person — Igors Volohovs.

AI Claude Code is a private tool that runs on its owner's own computer. On the owner's explicit command it creates entries in the owner's own Google Tasks and Google Calendar (including Google Meet links) and reads them back for the owner.

It is not offered to the public and has no other users.
