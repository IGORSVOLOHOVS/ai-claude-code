Privacy policy

Last updated: 22 October 2026.

AI Claude Code is a personal tool used only by its owner, Igors Volohovs. It is not offered to anyone else.

What it accesses

With the owner's consent it accesses the owner's own Google account:

  • Google Tasks — to create tasks and read open tasks;
  • Google Calendar — to create events and Google Meet calls and to read the owner's calendar.

How the data is used

Only to carry out the owner's own commands. Nothing is used for advertising, profiling or any purpose other than that.

Where the data is kept

The access token is stored only on the owner's own computer. Google data is not copied to any server of the app, because the app has no server.

Sharing

Google user data is not sold, transferred or disclosed to any third party.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
